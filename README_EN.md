A brand new decentralized virtual currency earning paradigm: no longer exchanging meaningless hash computing power for block rewards, but obtaining them by consuming AI inference tokens or contributing AI tokens to improve the community.

Motivation

Traditional Proof of Work (PoW) consumes huge amounts of electricity and computing power, but the hash values produced have no actual value in themselves. PoAIT (Proof of AI Token) proposes: tying the right to produce blocks to valuable AI work. Miners are no longer "computing power laborers", but providers of AI services or builders of the AI ecosystem.

Core Idea

Replacing hash operations with AI Token work
We define two types of valid AI Token work, both of which can earn block rewards:

AI Token consumption-type work: Miners provide AI inference services. Each time an inference token of a model is consumed (e.g., answering user questions, generating images), workload is accumulated.

AI Token community improvement-type work: Miners use AI Tokens to participate in ecosystem building, such as providing high-quality fine-tuning data, verifying model output quality, improving community knowledge bases, etc. Rewards can also be obtained based on contributed "effective AI token working hours".

Both types of work are ultimately converted into a unified workload metric to participate in block reward distribution.

Standardized workload metric: PoAIT Score
Different models and different tasks vary greatly in difficulty, so a complexity coefficient and contribution weight are introduced for unification:

PoAIT_Score = Consumed/used AI token equivalent × Task complexity coefficient

For inference services, the coefficient reflects the computational cost per token of the model (e.g., GPT‑4 is about 10 times that of a lightweight model).

For community improvement tasks, the coefficient is dynamically set by governance based on the scarcity and difficulty of the task type (data labeling, model evaluation, etc.).

The coefficient table is maintained by on-chain governance and can be initialized based on public benchmarks or community voting.

Verifiable execution: TEE as the trust foundation
The results of AI-related work are often non-deterministic and cannot be directly verified like hashes. We require miners to complete key operations within a TEE (Trusted Execution Environment, such as Intel SGX/TDX, NVIDIA Confidential Computing) and submit a hardware-signed "execution credential":

Prove that the inference result or community contribution was indeed generated by the specified model/process within the secure area, with input, output, and contributor ID being tamper-proof.

At the same time, introduce optimistic verification + fraud proof: challengers can replay or review the work and report cheating to receive economic incentives.

Blockchain Architecture
A dedicated Layer 1 built on Cosmos SDK, consensus using PoS + Tendermint BFT (second-level finality). The system is divided into four layers:

User layer: Users/consumers submit inference tasks or community improvement tasks, paying PoAIT tokens.

Service and contribution market layer (x/inference + x/community): Task matching, order book, contribution recording and management.

Secure execution layer (x/tee): TEE remote attestation, miner identity registration, result signature verification.

Incentive settlement layer (x/earnings): PoAIT score calculation, block subsidy and fee automatic distribution.

Consensus and network layer: Cosmos SDK + Tendermint, PoS+BFT, block time around 5 seconds.

Fundamental differences from existing virtual currency earning methods

Existing paradigm Typical projects Earning method PoAIT’s difference

PoW hash computing power Bitcoin, Litecoin Constantly trial-and-error calculating useless hash values Completely abandon hash spinning, using AI Token work (inference/community) as the basis for block production

PoS staking for interest Ethereum, Cardano Lock tokens to earn interest, no actual external work Must provide effective AI services externally or improve the ecosystem; staking is only an entry condition

Decentralized storage Filecoin Provide storage space and prove it Essentially still hardware resource consumption; PoAIT is AI intellectual resource consumption

AI model marketplace Bittensor Validator nodes subjectively score and rank We adopt objective token consumption equivalents and task coefficients, supplemented by TEE verifiability

TEE privacy computing Phala Network Provide privacy computing services Same TEE foundation, but PoAIT’s core innovation lies in AI Token workload measurement, supporting two contribution modes

Open issues to be resolved

Fairness of task coefficients: How to dynamically and decentrally maintain the complexity/importance coefficients of inference models and community tasks?

Contribution anti-Sybil: How to prevent meaningless volume brushing in community improvement-type work?

TEE hardware dependency: Does it create a centralization barrier for miners? Can we smoothly transition to zkML in the future?

Non-deterministic task handling: For random tasks like high-temperature chat generation, how to define a "correct" output?

Balance between two types of work: How should block subsidies be distributed between AI Token consumption-type and community improvement-type work? How to prevent one type from crowding out the other?
